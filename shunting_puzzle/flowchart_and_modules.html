Possible actions:

ActionDescription
Move EngineMove EE (with coupled wagons) to adjacent track via junction
CoupleAttach a wagon on same track to engine
DecoupleDetach a wagon from engine onto current track
Fly ShuntPush coupled wagon through junction; wagon rolls alone, engine stays

Selection strategy (BFS-optimal order):

  1. If a wagon is on engine's track and needs to go elsewhere → COUPLE
  2. If coupled wagon's destination is adjacent → MOVE or FLY_SHUNT
  3. If engine needs to reach a wagon → MOVE (alone if needed)
  4. If coupled wagon can't pass junction → FLY_SHUNT
